# Reliance Admin - User Management Module

## Overview
Complete user management interface built with Next.js and TailwindCSS, featuring:
- User filtering and search
- Status management
- Admin privileges handling
- Document verification
- Content moderation

## Features
- Complete user management interface
- Role-based access control
- Document verification system
- Content moderation tools
- Activity monitoring

## Tech Stack
- Next.js 14.1.0
- React 18
- TailwindCSS
- TypeScript

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/your-username/reliance-admin.git
cd reliance-admin
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```
