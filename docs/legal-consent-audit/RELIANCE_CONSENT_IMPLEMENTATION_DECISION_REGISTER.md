# RELIANCE CONSENT IMPLEMENTATION DECISION REGISTER

**Document type:** Approved product-decision register

**Status:** APPROVED

**Purpose:** This register maps the product-owner decisions incorporated into `RELIANCE_RECORDING_AND_CONSENT_WORKFLOW_SPEC_V1_1.md` to the workflow sections, implementation phases, and acceptance tests that must govern later engineering work. It changes no application behavior.

## Governing rule

Every decision below is approved. Engineering may choose technical methods during a separately authorized implementation task, but it may not change the approved business result. Where implementation uncertainty occurs, media remains Private, recording remains locked when required permission is absent, and public access is not expanded.
